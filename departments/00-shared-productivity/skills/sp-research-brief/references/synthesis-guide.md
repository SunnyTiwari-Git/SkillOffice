# Research synthesis guide

## Which sources count most, by question type

| Question type | Look first at | Then |
| --- | --- | --- |
| Decision ("what did we decide") | Meeting notes, formal emails, decision records | Chat thread conclusions |
| Status ("where are we") | Recent task lists and status updates | Recent messages |
| Factual or policy | Official documents, published policies | Confirming discussions |
| Document ("where is") | Shared folders, document indexes | Messages that link to it |
| Timeline ("when did") | Dated records across sources | Anything with a timestamp |
| Exploratory ("what do we know") | Everything relevant | Group by theme |

## Search tips when the platform's search is allowed

- Try the exact name first, then synonyms and abbreviations ("Kubernetes", "k8s", "cluster").
- When results are thin, broaden in this order: drop date limits, drop location limits, drop minor keywords, keep only the core topic.
- When the question is truly ambiguous (two different projects share a name), ask one short question. Otherwise answer for the likely meaning and note the other.

## Confidence

Combine three signals:

| Signal | Higher confidence | Lower confidence |
| --- | --- | --- |
| Freshness | Recent, especially for status questions | Older than a month for anything that changes |
| Authority | Official document, published policy, formal announcement | Draft, mid-thread chat, hearsay |
| Agreement | Several independent sources agree | Single source, or sources disagree |

How to say it:

- High: state it directly.
- Moderate: "Based on <source> from <date>, ... This may have changed since."
- Low: "I found only <source> from <date>, which is informal or old. Check with <role> before relying on it."

## Deduplication

Same point if: same or very similar content, same author, close dates, or one source refers to another. Merge into one point and cite all sources. Prefer the most complete version, then the most authoritative, then the most recent.

Keep separate if: different conclusions, different people's views, a later version changed an earlier one, or different time periods.

## How much to show

- 1 to 5 relevant items: answer, then each item with its detail.
- 5 to 15 items: answer, then themes with a short summary each, then the key sources.
- More than 15 items: answer, three to five key findings each with the number of supporting sources, top sources, and an offer to go deeper.

## Avoid

- Listing results source by source instead of answering.
- Including items that only match a keyword.
- Presenting uncertain information with the same confidence as well-supported facts.
- Summarizing so hard that the useful detail is lost.
