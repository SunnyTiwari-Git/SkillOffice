# Departments

Each department is one folder named `<number>-<slug>`, matching `registry/departments.yaml`. A department folder is created only when its build wave starts, so this folder never holds empty placeholders.

## Folder layout

```text
departments/<number>-<slug>/
├── README.md              What the department offers, playbooks, examples, platform test results
├── catalog.yaml           Generated by `skilloffice catalog`; one line per skill
├── manager/
│   ├── SKILL.md           The department manager (from core/templates/manager)
│   └── skill.yaml
└── skills/
    └── <skill-name>/
        ├── SKILL.md       Agent Skills format, six standard frontmatter fields only
        ├── skill.yaml     SkillOffice data: inputs, outputs, dependencies, context, risk
        ├── PROVENANCE.md  Source, commit, license, changes made
        ├── references/    Longer guides, loaded only when needed
        ├── assets/        Templates, checklists
        ├── scripts/       Only if essential; reviewed and pinned
        └── evals/         Test prompts and expected outcomes
```

## Build order

- **Pilot:** 06 Marketing, Content and PR, and 10 Software Development.
- **Waves 1 to 3:** the remaining software-company departments (00 to 17), about four per wave.
- **Later:** 18 E-commerce and Retail, 19 Supply Chain and Logistics, and the industry packs.

See `registry/departments.yaml` for the current status of each department.

## Adding a department

1. Add it to `registry/departments.yaml`.
2. Create the folder with the layout above.
3. Copy the manager template from `core/templates/manager/`.
4. Run `skilloffice validate` and `skilloffice catalog departments/<slug>`.
