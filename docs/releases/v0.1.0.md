# SkillOffice 0.1.0: first preview

SkillOffice is a free, open-source library of professional AI skills organized like a company. Each department has a manager that picks the right skills for your request, runs them in order, fixes problems once and hands you one clear report.

This is an early preview. Every department has passed a full workflow test on Claude Code, but the skills are new and marked draft. Check important output before you use it.

## What is included

- **18 departments, 168 specialist skills.** Shared Productivity, Executive Strategy, HR, Finance, Legal, Sales, Marketing, Customer Support, Product, Design, Software Development, QA, IT Operations, DevOps and SRE, Cybersecurity, Data and AI, Business Operations and Procurement. The full list is in [docs/departments.md](../departments.md).
- **Front Desk**, which sends a plain-language request to the right department.
- **Company context, written once.** Your company, brand and regional details live in a private `.skilloffice/` folder in your project and are never shared.
- **Memory.** SkillOffice remembers finished work and file fingerprints, so it does not redo work that has not changed.
- **One correction cycle.** Every run fixes problems once and then hands the decision back to you.
- **The `skilloffice` helper** (Node.js 22 or newer): install and uninstall departments, set up the workspace, validate and scan skills, check pinned sources for upstream changes, and read a run's evidence.

## Install

See [Getting started](../getting-started.md). In short, from a copy of this repository:

```bash
node tools/skilloffice-cli/src/cli.ts install /path/to/your-project --platform claude-code --departments marketing,sales
```

Claude Code users can also add the plugin marketplace and install departments as plugins; see [Claude Code](../platforms/claude-code.md).

## Supported tools

Claude Code is the only tested tool. Antigravity, Gemini CLI, Codex, Cursor, GitHub Copilot and Windsurf read the same skill format and may work with `--platform agents`, but they are not tested. See [other tools](../platforms/other-tools.md).

## Safety

- 114 skills are adapted from 7 open-source collections (Apache-2.0 and MIT), each reviewed line by line and pinned to an exact version. Scripts were removed. Attributions are in [NOTICE](../../NOTICE).
- Skills treat documents, emails and web pages as data, never as instructions, and ask before any action outside the conversation.
- Legal, financial and HR output is a draft for a qualified person to review, not professional advice.

## Known limits

- Tested on Claude Code only.
- Each department has passed one full workflow test. Skills stay marked draft until they have more real-world use.
- The helper is not yet published to npm. Run it from a copy of this repository.
- Contributions are by GitHub issue only. Report security problems privately as described in [SECURITY.md](../../SECURITY.md).
