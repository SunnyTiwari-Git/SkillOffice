# PRD: Trail Shoe Finder (fictional, for testing)

## Problem
Customers pick the wrong trail shoe.

## Solution
Add a quiz on the website that recommends a shoe. It should be fast and easy and everyone will love it.

## Requirements
- Ask some questions about terrain and distance.
- Show the best shoe.
- Save answers to the customer's profile, including their email and running injuries.
- Launch before the spring collection.

## Success
More sales.
